# Phoneme and Pitch Track-Transfer Study

The next research direction is the deferred phoneme and pitch track-transfer
study: preserve a source vocal's words, timing, and melody while rendering or
mixing it over a different instrumental track.

The study will evaluate a staged pipeline:

`source vocal -> phonemes + timing + F0 + optional energy -> target vocal -> target instrumental -> mix`

The source vocal supplies what is sung, when it is sung, and the melody. The
target instrumental supplies the new musical context. The full staged plan,
representations, ablations, metrics, and continuation instructions are in
[`docs/research-plan.md`](docs/research-plan.md#future-track-transfer-study-phoneme-and-pitch-alignment).
