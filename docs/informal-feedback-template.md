# Informal listening notes

Use this form only for internal engineering feedback. Do not collect
identifying information, present it as a study, or aggregate it into a claim
about human preference.

```yaml
run_id: ""
example_id: ""
conditions_heard: []
listener_role: researcher-or-developer
notes: ""
audible_artifacts: []
follow_up: ""
```

Describe concrete artifacts such as clicks, noise, timing drift, or audible
distortion. Keep model labels visible and preserve the associated run record.
